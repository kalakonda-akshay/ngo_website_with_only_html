# Lantern Learning Trust Website

A single-page responsive website for **Lantern Learning Trust**, an initiative operating free evening learning centres for children across rural village clusters.

## Features
- **Responsive Layout**: Adapts smoothly to mobile, tablet, and desktop screens with custom typography.
- **Dark Mode Support**: Automatically switches based on system color scheme preferences (`prefers-color-scheme`).
- **Interactive Timetable & Program Details**: Detailed daily schedule and program breakdown for classes 3 to 10.
- **Class Register**: Cluster-by-cluster breakdown of active centres, student counts, and volunteer metrics.
- **Client-Side Form Validation**: Working demo contact form with inline user feedback.
- **Zero External Dependencies**: Pure HTML5 and CSS with vector SVG artwork.

## Usage
Simply open `index.html` in any modern web browser or host it via GitHub Pages.
